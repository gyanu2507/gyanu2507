# Gyanu Mayank

B.Tech in Computer Science, NIT Patna. Based in Pune, India.

I work on AI agents and contribute to open source.

I design agent evaluations: broken starters with known failure modes, oracle solutions, and verifiers that recompute scores from artifacts. I’ve covered event-sourcing repair, systems contracts, and distribution shift with frozen baselines. I also put eval inside product agent loops (draft → score → revise), with cancel and timeouts through the tool layer.

Public writeup: [When the delta is fake](https://github.com/gyanu2507/agent-eval-suite/blob/main/docs/tech-report.md) ([DOI](https://doi.org/10.5281/zenodo.23829462), [PDF](https://github.com/gyanu2507/agent-eval-suite/releases/download/v0.1.1/tech-report.pdf)). Companion PRs on [Harbor](https://github.com/harbor-framework/harbor/pull/4003) and [Terminal-Bench](https://github.com/harbor-framework/terminal-bench/pull/2480).
