# Gyanu Mayank

Independent researcher working on agent evaluation and agentic systems.

B.Tech, Computer Science and Engineering, National Institute of Technology Patna. Based in Pune, India.

Focus areas: pass-bar design for agent tasks (named starter failures, oracles, artifact-backed scoring), evaluation inside product agent loops (draft → score → revise), and reliability through tool layers (cancel, timeouts, evidence grounding). Domains covered include event-sourced repair, systems contracts, and distribution-shift reporting.

Technical report: [When the delta is fake](https://github.com/gyanu2507/agent-eval-suite/blob/main/docs/tech-report.md) · DOI [10.5281/zenodo.23829461](https://doi.org/10.5281/zenodo.23829461)
